موقع هدية سلمى إلى سارة
=======================
فكّي ضغط الملف وافتحي index.html في المتصفح.

الأغنية مضافة داخل assets باسم song.mp3. الموقع يحاول تشغيلها تلقائيًا عند الفتح،
لكن بعض المتصفحات تمنع تشغيل الصوت دون تفاعل؛ في هذه الحالة اضغطي زر الأغنية أو أي مكان بالموقع.

شريط الصور يتحرك تلقائيًا، ويتوقف مؤقتًا عند التفاعل معه.
كروت الجرة تفتح بالضغط عليها.
